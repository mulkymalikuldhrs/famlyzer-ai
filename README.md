# Famlyzer AI

Autonomous Decision & Planning Intelligence for Life, Family & Finance.

- **7 AI Agents** for holistic decision support
- **4-Layer Memory** architecture
- **Knowledge Vault** with RAG
- Built with Next.js + Prisma + Tailwind CSS

## Getting Started

```bash
npm install
npm run dev
```

## Tech Stack

- **Frontend:** Next.js, TypeScript, Tailwind CSS
- **Backend:** Next.js API routes, Prisma ORM
- **AI:** Multi-agent system with RAG-powered memory
- **Database:** PostgreSQL via Prisma
